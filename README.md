# 📊 Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using **SQL** and **Power BI** to uncover purchasing trends, customer preferences, discount patterns, and sales insights. The objective is to transform raw transactional data into meaningful business insights through data cleaning, SQL analysis, and interactive dashboards.

This project demonstrates practical data analytics skills suitable for real-world business scenarios and data analyst internships.



## 🎯 Objectives

* Analyze customer purchasing behavior
* Identify top-selling products and categories
* Evaluate the impact of discounts on sales
* Discover customer demographics and spending patterns
* Build an interactive Power BI dashboard for business decision-making


## 🛠️ Technologies Used

* **SQL (MySQL)**
* **Python (Pandas)**
* **Jupyter Notebook**
* **Power BI**
* **Git & GitHub**


## 📊 Analysis Performed

### Data Preparation

* Imported CSV into Pandas
* Connected Jupyter Notebook with MySQL
* Loaded data into MySQL using SQLAlchemy
* Verified and managed database tables


### SQL Analysis

The project includes SQL queries to analyze:

* Total sales
* Revenue by category
* Top-selling products
* Customer purchase frequency
* Average purchase amount
* Discount utilization
* Seasonal shopping trends
* Gender-wise purchasing analysis
* Age group analysis
* Preferred payment methods
* Subscription behavior
* Customer review ratings
* Top 3 products in each category using Window Functions
* Common Table Expressions (CTEs)
* Aggregate functions
* Ranking functions

## 📥 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/Customer-Shopping-Behavior-Analysis.git
```

### 2. Import Dataset

Load the CSV file into Pandas.

### 3. Create MySQL Database

```sql
CREATE DATABASE customer_behavior;
```

### 4. Run SQL Script

Execute:

```
customer behavior sql code.sql
```

### 5. Open Power BI Dashboard

Open:

```
customer_behavior_analysis.pbix
```

using Microsoft Power BI Desktop.
